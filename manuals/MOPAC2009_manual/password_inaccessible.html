MOPAC Password inaccessible

If the password cannot be read by MOPAC, the program will print out the message 'File "12345678a12345678.mop" is currently inaccessible' and the job will stop.

Correcting this error depends on which operating system is being used.

Windows:

Make sure that the password exists, and can be read.  To do this:
Look in C:\Program files\MOPAC  and make sure that the file "password for MOPAC2009" exists. 
(The folder C:\Program files\MOPAC  must exist unless the environmental variable is set.)
If the environmental variable MOPAC_LICENSE is set, look in the appropriate folder.
Make sure that everyone has read permission for file "password for MOPAC2009"

Linux and Mac:

Make sure that the password exists, and can be read.  To do this:
Look in /opt/mopac and make sure that the file "password for mopac2009" exists. 
If the environmental variable MOPAC_LICENSE is set, look in the appropriate folder.
Make sure that everyone can read the contents of the folder where password_for_mopac2009 exists.
If necessary, change the permissions of the folder and file by using chmod +r <folder> and chmod +r password_for_mopac2009
 

Then re-run MOPAC using a normal (not the password) data set.
